# Slides

`spatial_transcriptomics_workshop.pptx` — 33 slides, with speaker notes on every one.
The notes carry the teaching points that are not on the slide: where people get
confused, what to cut when you run late, which exercise each slide sets up. Read them
before you present.

Roughly slides 1–20 are the day-1 lecture and 21–33 the day-2
lecture (15 min) plus the closing. Split them wherever suits you.
